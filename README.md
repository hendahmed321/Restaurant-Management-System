# Restaurant-Management-System

A web-based solution for restaurant ordering and management, built as a university project.

## Features

### For Customers
- Browse the digital menu with images
- Place orders for delivery/pickup
- View order status

### For Restaurant Staff
- Order management dashboard
- Inventory tracking
- Sales analytics
- Kitchen display system

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Database:** MySQL
