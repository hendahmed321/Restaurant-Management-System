# Restaurant-Management-System

A web-based solution for restaurant ordering and management, built as a university project.

## Features

### For Customers
- Browse the menu
- Place orders in cart
- View order status

### For Restaurant Staff
- Order management dashboard
- Update order status
- Sales statistics

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Database:** SQL Server
